Session'i kapatmadan once:

1. `asuna-tasks/task-index.md` oku — aktif task var mi? Bu session'da yapilanlari listele
2. Task durumlarini guncelle:
   - Tamamlananlar → COMPLETED, dashboard sayilarini guncelle
   - Yarim kalanlar → IN_PROGRESS birak veya notla PENDING'e cevir
3. Session notu yaz → `asuna-tasks/active/session-notes.md`:
   - Tarih, yapilanlar, yarim kalanlar, siradakiler, dikkat edilecekler
4. Bu session'da mimari karar alindiysa → `asuna-docs/DECISIONS.md`'ye ekle
5. Yeni gotcha/pattern varsa → `asuna-docs/MEMORY.md` guncelle
6. `CLAUDE.md` Mevcut Durum bolumunu guncelle (progress sayisi)
7. /git-full calistir — stage, commit, push
8. Kapanis: session ozeti + siradakiler + "Session kapatildi, degisiklikler push edildi."
